# Настройки ТВ: что меняем и как вернуть (Samsung UE40K6500, 2016, RU)

Состояние «до» фиксируется фото экранов + (если доступен командный канал) `vconftool get`.
Каждый пункт ниже — официальная настройка Samsung, откат делается тем же путём в меню.

## 1. Реклама и телеметрия (официальные переключатели)

Путь на этом ТВ (проверено по фото): **Home → Настройки → (меню) → Параметры конфиденциальности →
«Условия, политика конфиденциальности»** (Terms & Policy). Скриншоты: `backup/photos/09-privacy-settings.jpg`
и следующие.

| Пункт меню | Целевое состояние | Что отключает | Откат |
|---|---|---|---|
| Interest Based Advertisement / Реклама на основе интересов | **Отключить** | персонализированную рекламу в Smart Hub | включить обратно |
| Viewing Information Services / Информационные услуги просмотра | **Снять согласие** | ACR — сбор того, что смотрите (телеметрия просмотра) | вернуть согласие |
| Voice Recognition Services (если есть) | Отключить | голосовые сервисы | — |
| Nuance Voice Recognition (если есть) | Не соглашаться | — | — |
| Online Remote Management / Удалённое управление | **Выкл.** | удалённый доступ Samsung (и PIN) | включить |

Скриншот «до» обязателен: сохранить в `backup/<ts>/photos/settings-terms-before-*.jpg`.

## 2. Samsung TV Plus и автостарт

| Пункт | Целевое | Откат |
|---|---|---|
| `Меню → Система → Доп. настройки → Автостарт Smart Hub` | Выкл. (если не нужен автостарт Smart Hub) | Вкл. |
| `Меню → Система → Общие → Samsung Instant ON` | Выкл. (не держать процессы в stand-by) | Вкл. |
| TV Plus: строка/автозапуск (в 2016 — сервис `tvplus-service`) | см. `scripts/debloat.sh` | — |

## 3. Обновления ПО

`Настройки → Поддержка → Обновление ПО → Автообновление` → **Выкл.**
(чтобы прошивка не вернула рекламные сервисы и не сломала наши изменения).
Откат: Вкл.

## 4. Сеть (рекомендуется, если реклама останется)

DNS-блокировка на роутере (не меняет ТВ, легко откатить):
`ads.samsungads.com`, `samsungads.com`, `log-*.samsungacr.com`, `acr*.samsungcloudsolution.com`,
`*.samsungcloudcdn.com` (осторожно: последний также возит обновления приложений).
На роутере 192.168.0.1 — список хостов сохраняется в `backup/<ts>/dns-blocklist.txt`.

## 5. Что НЕ трогаем без явного согласия

- SmartThings (управление с телефона) — оставляем.
- Smart View / AirPlay / Game Mode — оставляем.
- Приложения из списка пользователя: YouTube, Кинопоиск, IVI, Wink, Okko, HDMI-входы — не трогаем.

## 6. Как фиксируем «до»

1. Фото каждого экрана настроек перед изменением.
2. `scripts/backup.sh` → `api_v2.json`, попытки списка приложений, `vconf/*`.
3. Для каждого изменения — строка в `backup/<ts>/CHANGES.md`: что, где, было → стало.
