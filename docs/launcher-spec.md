# AiTV — формальная спецификация логики лаунчера

Версия: 3.3 (2026-11-14). Платформа: Samsung UE40K6500, Tizen 2.4.0, WebKit/538.1.
Спецификация — источник истины для поведения; код (`launcher/AiTV/js/app.js`) обязан ей соответствовать.

## 1. Модель

**Состояния (S):**
| S | Описание |
|---|---|
| `dock` | главный экран: часы, док, фокус на плитке дока |
| `grid` | оверлей «Все приложения», фокус на плитке сетки |
| `samsung` | панель-подсказка Smart Hub (модальная, поверх `dock`) |
| `launching(appId,t0)` | с момента OK на плитке до момента, когда приложение вышло на передний план (не более 3 с) |
| `background` | лаунчер не в фокусе (открылось приложение или Samsung Smart Hub) |

**Фокус:** `dockIndex` (0..N-1, N = число плиток дока, последняя — «Все»), `gridIndex` (0..M-1, M = приложений в библиотеке), `gridCols` — фактическое число колонок сетки (измеряется по layout).

**Ключи пульта (keyCode):** ←37, →39, ↑38, ↓40, OK/Enter 13, Back 10009/461/27/8.
**События окна:** `focus`, `blur`, `visibilitychange`, `pageshow` (последние два на Tizen 2.4 могут не приходить; полагаться на `focus`/`blur`).
**Внешние сервисы:** `tizen.application.launch(appId)` — запуск web-приложения; `tizen.application.launchAppControl(eden_resume, APP_ID)` — возврат себя на передний план; `GET http://127.0.0.1:8001/api/v2/applications/<appId>` — статус (`{running, visible}`), доступен только с самого ТВ.

## 2. Инварианты (I)

- **I1 — OK на плитке запускает.** `OK` на плитке дока/сетки с `kind:"app"` вызывает `tizen.application.launch(appId)`. Лаунчер НЕ должен возвращать себя на передний план в течение `launching` (≤3 с) и после успешного запуска (пока приложение на экране).
- **I2 — Home остаётся за Samsung (v2.0).** Лаунчер НЕ перехватывает Home: нажатие Home и в лаунчере, и в приложении открывает Samsung Smart Hub (штатное поведение платформы). Перехват отменён по требованию владельца: «при запущенном лаунчере Home должен вызывать меню Samsung».
- **I3 — выход из приложения.** Возврат в лаунчер по Back из приложения обеспечивает сама Tizen-платформа; лаунчер не делает принудительных перезапусков по `focus`.
- **I4 — окно запуска.** Пока `now() - launchedAt < 3000` и `launchedApp != null`, любые `blur` игнорируются для I2.
- **I5a — режим «отдать память» (опционально).** Если у записи в `apps.json` стоит `"heavy": true`, лаунчер после успешного запуска этого приложения завершает себя (`getCurrentApplication().exit()`), отдавая память плееру: тяжёлые плееры стартуют заметно быстрее. Плата — после выхода из такого плеера возвращаться некуда, и ТВ остаётся на чёрном экране: вернуться можно вручную через Home → Smart Hub → APPS → AiTV. Поэтому **в примере конфигурации флагов `heavy` нет**: по умолчанию лаунчер остаётся в памяти и возврат по Back мгновенный.
- **I5 — нет фонового наблюдения (v2.0).** `visible` в `127.0.0.1:8001/api/v2/applications/<id>` на Tizen 2.4 не отражает передний план (проверено: у приложения на экране `visible:false`), `getAppsContext` не сообщает foreground, Home-клавишу public-приложение перехватить не может. Поэтому возврат в AiTV после Home из чужого приложения на этой платформе не реализуется; документированное ограничение. Возврат из приложения по Back обеспечивает сама Tizen (I3).
- **I6 — плитки Smart Hub больше нет (v3.0).** Проверено с камерой: `tizen.application.launch("org.tizen.menu"/"org.volt.apps"/"org.volt.firstscreen")` и `launchAppControl` с `eden_resume`/`default` возвращают success-колбэк, но НИЧЕГО не поднимают (с экрана не уходит наш app). Вывод: public-приложение на Tizen 2.4 не может открыть системные приложения Samsung. Мёртвая плитка удалена из дока и библиотеки, лишние привилегии `appmanager.*` убраны из манифеста.
- **I7 — подавление.** Пока `now() < homeSuppressUntil`, I2/I5 не срабатывают (владелец ушёл в Samsung Smart Hub).
- **I8 — HDMI/url/неизвестный id.** `kind:"input"` → `tizen.tvwindow` (fallback: тост «HDMI-вход»); `kind:"url"` → app control; пустой/`placeholder` appId → тост, ничего не запускается.

## 3. Переходы

| Из | Событие | Действие | В |
|---|---|---|---|
| dock | ←/→ | сдвиг `dockIndex` с циклическим переходом | dock |
| dock | ↑ | открыть `grid` (фокус 0) | grid |
| dock | OK на app-плитке | `launchedAt=now`, `startWatch(appId)`, `launch` | launching |
| dock | OK на «Все» | открыть `grid` | grid |
| grid | ←/→/↑/↓ | сдвиг `gridIndex` с переносом строк/колонок | grid |
| grid | Back | закрыть оверлей | dock |
| launching | приложение вышло на экран | `blur`; окно 3 с игнорирует I2 | background |
| launching | ошибка launch | тост, `stopWatch()` | dock |
| background | `focus` (Back из приложения / возврат) | `stopWatch()`, отмена таймера I2 | dock |
| background | `blur` (Home) | ничего: Samsung открывает Smart Hub | background |
| background | `focus` (Back из приложения) | лаунчер на экране | dock |

## 4. Приёмочные тесты

| # | Шаг | Ожидание |
|---|---|---|
| T1 | OK на RUTUBE | RUTUBE открылся; лаунчер не вернулся сам |
| T2 | Back из RUTUBE | лаунчер на экране без чёрного кадра |
| T3 | Home на лаунчере | открывается Samsung Smart Hub (штатно), лаунчер остаётся в фоне |
| T4 | Home внутри RUTUBE | открывается Samsung Smart Hub (ограничение платформы: перехват невозможен) |
| T5 | Smart Hub | недостижим программно на этом ТВ; входит в систему только кнопкой Home (см. I2) |
| T6 | Back из приложения | лаунчер на экране |
| T8 | Back в оверлее «Все приложения» | оверлей закрылся, фокус в доке |

## 5. Известные ограничения платформы

- Системные приложения (Smart Hub, Настройки) нельзя запустить из web-приложения (public): `SecurityError`.
- `document.visibilityState` на 2.4 не меняется при уходе в фон; надёжны только `focus`/`blur`.
- `eden_resume` перезагружает страницу лаунчера (~1–2 с) — это допустимая цена возврата.
