# Технические документы

Сняты с рабочего проекта на Samsung UE40K6500 (2016, Tizen 2.4.0). Служат приложением к
[PLAN.md](../PLAN.md) и [AI-GUIDE.md](../AI-GUIDE.md).

| Документ | О чём |
|---|---|
| [launcher-spec.md](launcher-spec.md) | Формальная спецификация лаунчера: состояния, инварианты I1–I8, таблица переходов, тесты T1–T6 |
| [final-report.md](final-report.md) | Итоговый отчёт: что сделано, чем подтверждено, ловушки Tizen 2.4, тупиковые пути |
| [root-assessment.md](root-assessment.md) | Почему root недоступен на этом ТВ: проверки браузера, SDB, совместимость методов |
| [devmode-dialog.md](devmode-dialog.md) | Диалог «режим разработчика»: точная последовательность клавиш, состояние за состоянием |
| [settings-before.md](settings-before.md) | Изменённые настройки приватности/OTA и как их вернуть |
| [capture-methods.md](capture-methods.md) | Способы визуальной проверки: камера, пульт по websocket, отсутствие сетевых скриншотов |

Пути к скриптам в документах относятся к полному рабочему проекту (см. вступление
[AI-GUIDE.md](../AI-GUIDE.md)).
