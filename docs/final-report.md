## Технические грабли, которые пришлось решить (для повторения на 2016 TV)

| Проблема | Решение |
|---|---|
| ТВ отвергает установку `install failed[118]` | нужен сертификат Samsung Public для DUID + permit; Tizen-CA сертификат не подходит |
| Современный Tizen Studio подписывает SHA-512, Tizen 2.4 понимает только SHA-256/SHA-1 | signer пропатчен на SHA-256 (`toolchain/tizen-studio/tools/tizen-core/tz` + Java `TizenIncrementalSigner`) |
| Package ID не 10 символов → 118 | package id ровно 10 символов: `AiTVLaunch`, `AiTVKeyApp` |
| Лаунчер показывал старый набор плиток на ТВ | на 2.4 XHR к `js/apps.json` из file:// блокируется → конфиг встроен в `js/config.js` (`gen_config.py`) |
| Установка через `sdb install` не работает | `sdb push` в `/opt/usr/apps/tmp` + `sdb shell 0 vd_appinstall <package> <path>` |
| `sdb shell` закрыт (intershell disabled) | разрешены только отдельные команды: `0 applist`, `0 vd_appinstall`, `0 vd_appuninstall`, `0 was_execute`, `0 getduid`, `0 getappinstallpath`, `0 uname` |
| `sdb pull` не поддерживается | бэкап только через stdout команд и REST API |
| Скриншоты по сети невозможны | проверка = фото с телефона + REST `/api/v2/applications/<appId>` (running/visible) + `0 applist` |

## Ограничения (retail-прошивка, без root)

- Кнопку **Home** нельзя переназначить: `home_appid` пишется только через vconf, командного канала на
  Tizen 2.4 нет. Smart Hub остаётся системным «Home»; AiTV запускается из Apps / «Автозапуск последнего
  приложения».
- Предустановленные приложения **нельзя удалить/отключить** (ошибка 132). Реально доступно: настройки
  приватности, автообновление, уборка плиток Smart Hub, DNS-блокировка рекламы на роутере.
- Root для этой модели по публичным методикам не подтверждён (SamyGO K-root рассчитан на другие
  прошивки/платформы), поэтому «полное» выключение рекламных сервисов на уровне процессов недоступно.

## Как откатить всё

```bash
./scripts/restore.sh     # удалит AiTVLaunch + AiTVKeyApp, напомнит какие настройки вернуть
```
Настройки приватности возвращаются в меню ТВ (см. `docs/settings-before.md`). Заводские приложения,
Smart Hub и аккаунт Samsung не затрагивались.

## Дополнительно по просьбе владельца (быстрый возврат в лаунчер)

- Плитка YouTube заменена на **RUTUBE**: приложение YouTube на этом ТВ не работает (чёрный экран даже
  при запуске напрямую через `0 was_execute 9Ur5IzDKqV.TizenYouTube`) — это не баг лаунчера.
- AiTV ужат: обои 1280×720 (1.2 МБ вместо 2.7), ленивая загрузка иконок «Все приложения», пакет
  1.9 МБ вместо 3.6 МБ.
- Возврат из любого приложения: `background-support="enable"` + repaint на visibilitychange/focus/
  pageshow + отказ от декодирования новой обоины при возврате → лаунчер появляется мгновенно
  (подтверждено владельцем).
- Подпись/установка: `tizen package -s samsung` + `sdb push` + `0 vd_appinstall AiTVLaunch`.


## Итерация v3.0 — поведение кнопок (по требованиям владельца) и визуальная самопроверка

Формальная спецификация поведения — [launcher-spec.md](launcher-spec.md) v3.0.

| Действие | Поведение | Проверка |
|---|---|---|
| OK на плитке приложения | запускает приложение (`tizen.application.launch`) | камера: RUTUBE открылся (`backup/photos/20..22`) |
| Back в приложении | Tizen возвращает лаунчер | платформенное поведение, подтверждено ранее |
| Home в лаунчере | **Samsung Smart Hub** (штатно), лаунчер ничего не перехватывает | камера: `backup/photos/24-camera-home-samsung-smarthub.jpg` |
| Home внутри приложения | Samsung Smart Hub (перехватить нельзя) | ограничение платформы, см. ниже |

Почему «Home из приложения → AiTV» не реализуемо на этом ТВ (проверено с камерой и телеметрией):
- `127.0.0.1:8001/api/v2/applications/<id>.visible` на Tizen 2.4 **не отражает передний план**
  (у приложения на экране `visible:false`, `running:true`);
- `tizen.application.getAppsContext()` не сообщает foreground (только appId/pid, список не меняется при Home);
- `document.visibilityState` при уходе в фон не меняется (только focus/blur);
- системные приложения (Smart Hub `org.tizen.menu`, `org.volt.apps`, `org.volt.firstscreen`,
  `org.tizen.homesetting`) нельзя ни запустить (`SecurityError`), ни поднять: с привилегиями
  `appmanager.launch`/`application.info` `tizen.application.launch()` возвращает success, но экран
  не меняется; `launchAppControl(eden_resume/default)` — то же.
Поэтому плитка «Smart Hub» удалена (это был мёртвый элемент), а привилегии `appmanager.*` убраны из манифеста.

## Инструмент визуальной проверки (камера Mac)

`TeleCam.app` (в корне проекта) — мини-приложение: берёт кадр с камеры Mac каждые 2 секунды и кладёт в
`backup/live/tv-latest.jpg`. С его помощью агент сам снимал экран ТВ и проверял шаги, не отвлекая владельца.
Запуск: `open TeleCam.app` (один раз система спросит доступ к камере), остановка: `pkill -f TeleCam`.


## Итерация v3.2 — скорость запуска и память

| Что | До | После |
|---|---|---|
| Пакет лаунчера | 1.99 МБ | **1.27 МБ** (обои 960×540, иконки 176 px) |
| Старт тяжёлого плеера (Wink) при живом лаунчере в фоне | >24 с до UI | **~10 с**, если лаунчер отдал память |
| Возврат по Back из приложений | мгновенный | **мгновенный** (лаунчер остаётся жив) |

Механика: в `apps.json` можно пометить приложение `"heavy": true` — тогда лаунчер после его
запуска вызывает `tizen.application.getCurrentApplication().exit()` и освобождает память.
Это ускоряет старт тяжёлого плеера, но после его выхода ТВ остаётся на чёрном экране:
возврат вручную через **Home → Smart Hub → APPS → AiTV**. Поэтому по умолчанию флаг выключен.
