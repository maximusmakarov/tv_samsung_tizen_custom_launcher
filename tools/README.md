# tools/ — обёртки инструментария

В этом каталоге лежат **обёртки**, а не сами бинарники: Tizen Studio, `sdb` и Apps2Samsung CLI —
сторонние программы, которые нужно поставить локально (см. `docs/` и `PLAN.md`, фаза 2/6).

| Скрипт | Что делает |
|---|---|
| `sdb.sh` | запускает `sdb` из `toolchain/bin` (или из `$SDB_BIN`) |
| `tizen.sh` | запускает Tizen CLI из `toolchain/tizen-studio`, чинит `sdk.info` при переносе папки |
| `tv-ready.sh` | проверка готовности ТВ: ping, порт 26101, `sdb devices`, Apps2Samsung TV |
| `telecam/telecam.swift` | камера-снималка для визуальной самопроверки (macOS) |

Обёртки предполагают структуру полного рабочего проекта (`toolchain/…`). Если вы ставите
Tizen Studio в другое место — задайте `SDB_BIN`, `TIZEN_SDK_INSTALLED_PATH` или положите
скрипты в свою структуру.

**Проверено на:** macOS + Samsung UE40K6500 (2016, Tizen 2.4.0). Другие ОС/модели — работает
общий подход, но команды и пути нужно перепроверять.
