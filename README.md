# Samsung Tizen TV Custom Launcher — инструкция и план

Пошаговое руководство, как превратить старый Samsung Smart TV (Tizen) в быстрый минималистичный
медиацентр со своим лаунчером в стиле Apple TV: убрать рекламу/телеметрию штатными настройками,
поставить собственный главный экран с доком и меняющимися обоями, вернуть управление пультом и
проверить каждый шаг без «веры на слово» — по кадрам с камеры.

Репозиторий содержит **не код, а методику**: план работ, инструкцию для ИИ-агента и технические
документы, снятые с реального проекта на Samsung UE40K6500 (2016, Tizen 2.4.0).

## Результат, который вы получите

- Собственный **домашний экран** (web-app для Tizen): часы, док избранных приложений,
  меняющиеся обои с природой, сетка «Все приложения», полная навигация обычным пультом.
- Приложения запускаются с плитки; возврат из лёгких приложений — мгновенный; из тяжёлых
  плееров (Wink/Okko) лаунчер возвращается автоматически через внешний watchdog на Mac.
- Реклама и телеметрия выключены **штатными переключателями Samsung** (ничего не удаляется,
  всё обратимо), подготовлен DNS-блоклист для роутера.
- Установка — своим сертификатом Samsung Public, привязанным к DUID телевизора.
- Каждый шаг подтверждён кадром экрана/логом; есть restore-скрипт и документация.

## Пошаговый план (кратко)

Полная версия с критериями готовности — в [PLAN.md](PLAN.md).

1. **Подготовка** — рабочая копия, Mac в той же сети, план отката.
2. **Разведка ТВ** — найти IP, снять «паспорт» через REST (`/api/v2/`), узнать модель/прошивку/DUID.
3. **Режим разработчика + SDB** — включить, подключиться, проверить `applist`.
4. **Проверка root-возможности** — браузер/WebAssembly, возможности SDB, совместимость методов.
   На retail 2016 root недоступен → идём путём «штатные настройки + свой web-лаунчер».
5. **Бэкап и обратимость** — `backup.sh`, фото настроек, `CHANGES.md`, проверка restore.
6. **Реклама и телеметрия** — переключатели приватности, OTA выкл., DNS-блоклист; ничего не удалять.
7. **Своё приложение** — сертификат Samsung Public, манифест (package id ровно 10 символов,
   подпись SHA-256), сборка → `push` → `vd_appinstall` → `was_execute`.
8. **Лаунчер** — встроенный конфиг (XHR на `file://` заблокирован), лечение `focus`/`blur`,
   лёгкие обои/иконки, тяжёлые приложения отдают память.
9. **Проверка камерой** — `TeleCam.app`/`tv/snap.py` + `tv_remote.py`, приёмочные тесты T1–T6.
10. **Сдача** — README, спека, отчёт, restore, watchdog; всё проверено.

## Быстрый старт

1. Прочитать [PLAN.md](PLAN.md) (или отдать [AI-GUIDE.md](AI-GUIDE.md) ИИ-агенту вместе с папкой проекта).
2. Пройти фазы по порядку: каждая фаза заканчивается проверкой и артефактом (фото/лог/файл).
3. Остановиться и спросить владельца там, где план помечает «спросить»: приложения, которые
   нужны, разрешение на изменения, DNS-блокировка.

## Критичные ограничения (проверено на UE40K6500)

- **Root недоступен**: WebKit 538.1 без WebAssembly, нет подходящих эксплойтов; SamyGO K-root
  только для `T-JZ*`/`T-HKMFK*` ≤ 1169.2, USB-root Kant-M2 — 2018+/Tizen 4.0.
- **Кнопку Home перехватить нельзя** на retail-прошивке — Home всегда открывает Samsung Smart Hub.
- **Системные приложения (Smart Hub, настройки) нельзя ни запустить, ни поднять** из своего
  web-приложения, даже с привилегиями `appmanager.*`.
- **Скриншотов по сети нет**: Tizen 2.4 не отдаёт экран — проверка только камерой.
- **Тяжёлый плеер убивает фоновое приложение**: лаунчер отдаёт память (`exit()`) после запуска
  Wink/Okko, возврат обеспечивает Mac-watchdog.

Подробнее — [docs/final-report.md](docs/final-report.md) и [docs/root-assessment.md](docs/root-assessment.md).

## Безопасность и откат

- Ничего не удаляем и не отключаем в системе: только штатные переключатели и собственный UI.
- Перед изменениями — бэкап (`backup/<timestamp>/`) и запись «было → стало» в `CHANGES.md`.
- Все настройки приватности возвращаются теми же пунктами меню (таблица в
  [docs/settings-before.md](docs/settings-before.md)).
- Свой лаунчер можно удалить в любой момент: `vd_appuninstall <package>` по SDB.

## Совместимость

Методика выросла из Samsung **UE40K6500** (2016, Tizen 2.4.0, `16_HAWKM_FHD`). На других
моделях работает общий подход, но **все ID, версии и возможности нужно перепроверять**:
`applist` даёт актуальные app id, `/api/v2/` — платформу, тесты камерой — фактическое поведение.
Инструкция для ИИ начинается с этих проверок специально, чтобы не переносить факты вслепую.
